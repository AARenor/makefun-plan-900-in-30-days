The program writes the 30-day plan, 262 code points in UTF-8 with no trailing newline, to `entry.txt` inside `/output`, or inside `$MAKEFUN_OUTPUT_DIR` when that variable is set, creating the directory if it is missing. The text comes from `plan_text()` and the destination from `output_path()`. Run it with `python3 main.py`.
